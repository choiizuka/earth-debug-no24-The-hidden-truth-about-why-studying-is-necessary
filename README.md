#  子供の頃、よくこう言われることがあった「勉強しなさい」多くの人もそうではなかっただろうか。

幼少期に交通事故で父が亡くなり「人はいつかこの世界から必ずいなくなる」ことを明確に認識した。8歳の時から人の死について考え続けていた。

父が亡くなったので母が企業に就職して不在だったために祖父母の住む近隣の地域へと引っ越しをした。その間に祖母が張り切って「面倒を見る」と言って母の不在中に子供達の世話を見ようとした結果、「勉強しなさい」と勉強を強く強要する態度だったために、弟が反発して暴言を吐いてしまった。「クソ婆あ」

その途端に売り言葉に買い言葉が始まり「クソ婆あとはなんだ！」「みんな言ってるよ！」「みんなって誰だ！」これで夜、母と母の姉が電話で悪口を言っていると祖母本人に暴露され、家庭内では祖母との連絡が１年途絶える大騒動になったのだけど、日本全国こんな事実があったことをオレたち以外には誰も知らない。

さて、「勉強をしなさい」と言ってもこれはどのような意味で言っているのかという問題がある。これについてオレ自身は明確な回答をすでに持っているが、世の中には勉強に対するさまざまな定義があるはずだ。そのどれもが必ずしもどれが正解でどれが間違いかをここで決めるつもりはない。ただオレという人間が”勉強”というものをどのように活用することが最も有効と考えているのかその話をしようと思う。そしてそれは現在の社会の仕組みにおける勉強の意味合いとはかなり違うものだということは、間違いのない前提として話を進めよう。

勉強とは何か

　まず、このことを明確にしよう。勉強とは何か、勉強の意味とは、その人生を生きるその人自身にしか決定できないという事実だ。なぜなら、その人生を生きるのはその人自身なのであって、他人ではない、誰もその人には成り代わることができないからである。

社会における勉強の定義

　この社会における勉強の定義について、今現実のこの社会において、勉強というものが人々によってどのように行われているのか、その結果を分析した上で帰納法に導き出された結論を並べる。

それ以外の勉強の事例

　一方で、上記に当たらない明確な勉強の事例がある。

タルムードのような教育法（古代ユダヤから伝わるユダヤ人の間の教育法）

広く見ればこれらも勉強に違いないことは明白である。しかも人類のうちの多数がそれをやっていないことも明白である。故に勉強という用語を日常的に使ってはいても、世界および歴史的に過去存在した勉強と呼べるすべてを、すべての人が必ずしも認識、認知、理解をしていないことは明らかな事実である。

オレの考える勉強の優位性とその解説

　人生にはさまざまな問題が起きる。時には、父が亡くなったり、例えば愛し合って結婚した相手が亡くなってしまうかもしれない。それだけではない予期しないさまざまな問題が起きる。

時に、世の中には困難な生活環境の中で暮らしている人たちがいる。必ずしも恵まれず、経済的であったり、家庭不和、トラブル、いろんな問題が起こる。

そんな時、どうやって問題を解決することができるのか、また解決できなくても次へと人生を進めるためには、他人をあてするだけでは解決するとは限らない。

何かが起きた時、また、今置かれている状況から抜け出すためには、今置かれている問題から逃げたり、解決したり何らかの方法が必要になる。ここで必要なのは考える力である。ユダヤのタルムードでは考える力を身につけることを意図して作られた教育スタイルになっている。

それ以外にも哲学や禅問答のように議論を重ねることによって、思考力を身につけるための訓練の方法が用意されている。

西洋でもディスカッションの文化があり、共通するのは、これらの議論というのはその議論によって必ずしも決定を下すことではなく、議論を深めることで理解を深めるという機能を持っているという事実である。しかし議論をしたからと言って必ずしもその結論が宇宙の真理にはなり得ない。

例えば、アスリートや音楽家が長年のトレーニングの結果、成果を出しているとするなら、思考力についても鍛えたのとそうでないのでは明らかに違うだろう。しかしながら、社会を見ると思考停止を促すような機能、風潮が散見される。

これは問題解決や、今置かれている問題からの離脱の可能性を狭めるだけであり、もし本来人間の幸福を第一義とし、全人類を幸福にしようと考えるとすれば、オレなら全人類にこのように言うだろう「自分の頭で考える力を身につけるべきだ」。

歴史的にはこれと同じことを言った人物が複数人存在する。例えばソクラテスであり、例えばブッダである。それは一体どのような意見であるのかは今後レポートにまとめたいと思う。
